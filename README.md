# PUENTE SOLIDARIO

**Puente Solidario** es una plataforma web diseñada para conectar pequeñas organizaciones sin fines de lucro con personas interesadas en realizar donaciones y contribuir a distintas causas sociales.

## Descripción del proyecto

Puente Solidario es una plataforma que busca facilitar la conexión entre pequeñas organizaciones sin fines de lucro y personas que desean colaborar con causas sociales.

Muchas organizaciones pequeñas tienen dificultades para darse a conocer debido a la falta de recursos, tiempo o herramientas de difusión. Al mismo tiempo, existen personas interesadas en donar que buscan descubrir nuevas iniciativas y generar un impacto directo en la comunidad.

Nuestra propuesta consiste en ofrecer un espacio donde estas organizaciones puedan presentar sus proyectos, publicar campañas y comunicar sus necesidades, mientras que los usuarios pueden conocerlas y realizar propuestas de donación.

De esta manera, buscamos ampliar la visibilidad de las pequeñas ONG y facilitar nuevas oportunidades de colaboración.

## Funcionalidades principales

La plataforma cuenta con dos tipos de usuarios, cada uno con funcionalidades específicas:

### Organizaciones

- Registro e inicio de sesión como organización.
- Creación y administración de publicaciones.
- Difusión de campañas y necesidades de donación.
- Recepción de propuestas de donación realizadas por los usuarios.
- Posibilidad de aceptar las propuestas recibidas.

### Usuarios / Donantes

- Registro e inicio de sesión como usuario.
- Exploración de las organizaciones registradas.
- Visualización de campañas y necesidades de ayuda.
- Envío de propuestas de donación a las organizaciones.
- Posibilidad de establecer contacto con las organizaciones una vez aceptada la propuesta.

### Sistema de donaciones

El sistema permite que los usuarios interesados envíen propuestas de donación a las organizaciones. Una vez recibida y aceptada la propuesta, ambas partes pueden ponerse en contacto para coordinar los detalles de la colaboración.

## Instalación y ejecución

Para ejecutar el proyecto en un entorno local, es necesario seguir los siguientes pasos:

1. **Configurar la base de datos:** abrir SQL Server y ejecutar el archivo de base de datos incluido en el proyecto, identificado como `ESTA BD`.
2. **Abrir el proyecto:** cargar la solución completa en Visual Studio.
3. **Configurar el entorno:** verificar que la conexión con la base de datos esté correctamente configurada.
4. **Ejecutar la aplicación:** abrir una terminal desde Visual Studio y ejecutar el proyecto.

Una vez completados estos pasos, la aplicación estará disponible en el entorno local.
